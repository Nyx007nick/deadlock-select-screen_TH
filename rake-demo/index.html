Source audit, attribution, and editing notes

The wiki's Mina source was checked directly. Its raw Wikitext calls {{AbilitySection}}; the rendered Mina page/API supplies the actual Rake markup, displayed values, and image URLs. This standalone file recreates only the Rake card and does not embed or hotlink the whole wiki page.

PartSource / implementation
HTML structure Adapted from rendered Mina Rake markup: ability-card, ac-header, ac-info-section, ability-mainbox, and ability-upgrade. Trimmed and rebuilt for a single standalone card.
CSS Wiki class names and visual cues were inspected from the rendered page's TemplateStyles. Responsive styling and this page's card layout are newly written; selected hover/active colors and motion are based on the verified ability-upgrades CSS.
JavaScript Vanilla JS reproduces the inspected wiki upgrade gadget behavior: clicking a tier applies it plus lower tiers; clicking an active tier removes it and higher tiers. Numeric stats update locally.
Ability text and values Checked against Mina — Rake and the rendered MediaWiki API. The visible Tier 5 description does not state a Spirit-scaling amount; the displayed ×1.5 is calculated from this project's local ability data (+1.2 added to the base ×0.3).
Images All image URLs below were found in the rendered Rake markup: Rake.png, CastRange.png, AttributeIconTechCooldown.png, Spirit_scaling.png, Spirit_damage.png, Healing.png, and Ability_point.png, served from cdn.deadlock.wiki.
